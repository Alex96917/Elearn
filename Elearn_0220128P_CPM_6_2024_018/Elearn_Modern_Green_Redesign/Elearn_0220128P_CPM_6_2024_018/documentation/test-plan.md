# Functional test plan
| Test | Action | Expected result |
|---|---|---|
| Registration | Create learner account | Learner dashboard opens |
| Login | Use learner demo account | Learner dashboard opens |
| Instructor login | Use instructor demo account | Instructor dashboard opens |
| Role restriction | Open instructor page as learner | Access is denied and redirected |
| Search | Search course title | Matching courses appear |
| Filter | Choose topic and level | Course list is filtered |
| Enrollment | Enroll in a course | Course appears in learner dashboard |
| Progress | Mark lessons complete | Progress increases and persists |
| Assignment | Submit complete form | Submission appears in list |
| Grading | Grade a submission as instructor | Grade is saved |
| Certificate | Complete course to 100% | Certificate appears |
| Community | Join or create club | Membership/list updates |
| FAQ | Expand a question | Answer is displayed |
| Responsive | Resize browser to mobile width | Navigation and layout adapt |
