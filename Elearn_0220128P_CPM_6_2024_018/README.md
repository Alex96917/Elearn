# Elearn – Online Learning Platform
A browser-only e-learning prototype built with HTML5, CSS3 and Vanilla JavaScript.

## Run the project
1. Extract the project folder.
2. Open `index.html` in a modern browser (Chrome, Edge or Firefox).
3. For best results, use a local static server such as VS Code Live Server. No backend is required.

## Demo accounts
- Learner: learner@elearn.test / learn123
- Instructor: instructor@elearn.test / teach123

## Important
This is an assessment prototype. Authentication, enrollment, assignments, grading, clubs and progress are simulated with `localStorage`. It is not secure production authentication and data remains in the current browser profile. Do not enter real passwords or sensitive information.

## Main pages
Home, Login, Register, Learner Dashboard, Course Catalogue, Course Details, Learning, Assignments, Certificates, Instructor Dashboard, Community, Help/FAQ and About.

## Evidence
Save your own screenshots in `screenshots/` while testing the application. Suggested evidence checklist is in `documentation/evidence-checklist.md`.


### Theme preference
The navigation includes a Dark mode / Light mode toggle. The selected theme is saved in browser localStorage (`elearn_theme`) and is applied across all pages.


## Modern green redesign
The interface uses Elearn's modern minimal visual system with primary colour #26CC00, responsive layouts, educational course imagery and a persistent light/dark theme. Open `index.html` in a modern browser to run the front-end prototype. The project uses localStorage for demonstration data and does not require a server. Internet access is required for the externally hosted Unsplash course and hero images and Google Fonts.
