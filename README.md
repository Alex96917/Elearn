## 📌 About the Project

**Elearn** is a browser-based Online Learning Platform developed as an academic assignment project under the TVET CDACC Computer Programming programme.

The project was designed to demonstrate practical skills in front-end web development using HTML5, CSS3 and JavaScript.

The platform provides a digital learning environment where learners can register, access courses, monitor their learning progress, submit assignments and interact with other learners. It also provides instructors with tools to review learner submissions and manage learning activities.

The system was developed entirely using client-side technologies without server-side processing or a central database.

## 🎯 Project Objectives

The main objectives of this assignment were to:

- Design and develop a functional online learning platform.
- Implement learner and instructor registration and login interfaces.
- Develop role-based dashboards.
- Create a course catalogue with search and filtering capabilities.
- Enable learners to enrol in courses and access learning modules.
- Implement learning progress tracking.
- Provide assignment submission and grading functionality.
- Develop a certificate viewing and printing feature.
- Provide community clubs and learner support pages.
- Create a responsive and accessible user interface.
- Apply JavaScript and browser LocalStorage for interactive functionality and data persistence.

## 🚀 Getting Started

Elearn is a front-end web application and does not require a backend server or database installation.

### Requirements

- A modern web browser.
- A computer running Windows, Linux or macOS.
- Visual Studio Code (optional).
- Internet connection for externally hosted fonts and images.

### Installation

1. Clone the repository:

```bash
git clone https://github.com/Alex96917/elearn-online-learning-platform.git
```

2. Navigate to the project directory:

```bash
cd elearn-online-learning-platform
```

3. Open the project folder in Visual Studio Code.

4. Open `index.html` in your browser.

Alternatively, use the VS Code Live Server extension to run the application locally.

## 💾 Data Storage and Application Logic

The application uses JavaScript and browser LocalStorage to retain demonstration data, including:

- User registration details.
- Login session information.
- Course enrolments.
- Learning progress.
- Assignment submissions.
- Grades and feedback.
- Community information.
- Theme preferences.

Since the project does not have a backend database, stored information is browser-specific and is not synchronised across different devices.

## ⚠️ Project Limitations

This project was developed as a front-end academic assignment. It is a demonstration application rather than a production-ready learning management system.

Current limitations include:

- No server-side processing.
- No central MySQL database.
- Browser-based demonstration authentication.
- No secure cloud-based assignment file uploads.
- No real-time communication.
- No cross-device data synchronisation.
- No production-grade security implementation.
